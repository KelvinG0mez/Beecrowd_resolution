# 🐝 Exercícios Resolvidos - Beecrowd (URI Online Judge)

Este repositório foi criado para armazenar e organizar as minhas soluções dos desafios de programação propostos na plataforma **Beecrowd**. O objetivo principal é praticar lógica de programação, estruturas de dados, algoritmos e melhorar a eficiência do código.

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem Principal:** Python 3.x
* **Editor de Código:** Visual Studio Code (VS Code)
* **Plataforma de Treinamento:** [Beecrowd](https://www.beecrowd.com.br/)

---
